## 🚀 So findest du das passende Projekt

1. **Projekt öffnen:** In der Übersicht oben den Projektordner auswählen.
2. **Dateien verstehen:** Jede Ordnerebene hat eine README mit Erklärung und Verweisen.
3. **Mit ChatGPT/Codex weiterarbeiten:** Den zugehörigen [Projekt- oder Modul-Prompt](promts/README.md) verwenden.
4. **Vor produktivem Einsatz:** Skripte, Zugriffsrechte, Geheimnisse und Backups überprüfen.
