# Webfunktionen

| URL | Funktion |
|---|---|
| `/` | Status / Uebersicht |
| `/wifi` | WLAN-Scan und WLAN-Daten |
| `/config` | Display, LEDs, FTP, MQTT, API, Hostname |
| `/statuses` | Farbe und Effekt je Status |
| `/system` | RSSI, Akku, RAM, Dienste, Firmwarestand |
| `/update` | Firmwareupdate `.bin` |
| `/config/backup` | Konfiguration herunterladen |

Bei Konfigurationsaenderungen wird die vorherige Version nach `/config/config.bak` gesichert.
